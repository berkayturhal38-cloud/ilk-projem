# Changelog

All notable changes to **Turhal Smart Fibonacci PRO** are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/) and Semantic Versioning.

## [1.0.0] - 2026-06-30
### Added
- Initial release.
- Pivot-based swing detection with adjustable sensitivity (ZigZag-style memory).
- Trend-aware direction: Auto (swing structure) / EMA filter / Manual Up / Manual Down.
- Fibonacci retracement levels (0, 0.236, 0.382, 0.5, 0.618, 0.786, 1.0) with per-level toggle + color.
- Fibonacci extension levels (1.272, 1.414, 1.618, 2.0, 2.618).
- Golden Zone highlight box (configurable bounds + color).
- Price/ratio labels with size control.
- Soft fills between consecutive retracement levels.
- Themes: Dark / Light / Neon.
- Info dashboard table (trend, high/low, range, golden zone, current retracement %).
- Multi-timeframe confluence lines (HTF 0.5 / 0.618).
- Alerts: golden zone entry, 0%/100% break, key level touch (runtime + alertcondition).
